I'm a solo developer, assisted by AI, focused on long-context LLM competency:
local-first memory techniques, portable ways of interacting with models, and
making AI plug-&-play — an AI sysadmin capable of wiring into the host board's
firmware-level controls. Around that research I build an ever-growing software
suite of wired functions, tests, and logs, as the test-bed for bare-metal performance
of AI on Linux.

## 🚀 Featured Projects

**[Splinter-Memory](https://github.com/sky-is-green/Splinter-memory)** - Long-context curation-layer capable of selecting and retaining valuable context within memory before FIFO, while allowing the useless context to be forgotten, by using a cheap CPU encoder. Beats FIFO in all preliminary testing. [white-paper](https://github.com/sky-is-green/Strata-memory/blob/StrataMemory-test/STRATA-WHITE-PAPER.md)
